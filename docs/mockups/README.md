# Static UI design studies

These are documentation assets for the [running-screen review](../24-running-screen-design.md). They are not screenshots, executable prototypes or implemented application screens. Data, paths and code snippets are fictional. Exact colors, spacing and glyphs are illustrative; the images do not prove terminal-cell fit at 80×24.

The studies use the agreed semantic color roles and example RGB values from the main UI draft. The SVGs contain only drawing/text elements, not scripts or external resources. No runtime or project dependencies were added to create them.
